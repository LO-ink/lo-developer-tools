# Токен бота и сообщения групп

Токен LO имеет формат `<bot_id>:<43 символа base64url>`. Передавайте его только серверному транспорту. Не помещайте в веб-бандл, репозиторий, логи, URL приложения или отчёт проверки. При утечке отзовите токен в LO Connect и обновите серверную конфигурацию.

Пример правила для поиска секретов — [security/gitleaks.toml](../security/gitleaks.toml). Подключайте его к своей конфигурации gitleaks. Совпадение шаблона требует проверки; тестовые значения тоже могут подходить под формат.

Чтобы читать все сообщения группы, включите соответствующий флаг в настройках бота в LO Connect. SDK не меняет этот доступ. `getIdentity().canReadAllGroupMessages` отражает значение `can_read_all_group_messages` из getMe. Проверяйте его после изменения настройки; не считайте присутствие бота в группе разрешением читать все сообщения.

Права секретаря задаются владельцем отдельно. Доступ к группе, токен бота и право отправки от имени владельца не взаимозаменяемы.
